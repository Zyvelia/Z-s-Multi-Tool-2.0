# Borderlands 4

This folder contains the Borderlands 4-specific portion of the universal Save Editor.

## Contents

- `tools.py` — BL4 serial parser/serializer, gear editor, workspace, validation, and BL4-specific UI.
- `catalog.json` — BL4 family/manufacturer/category metadata used by the editor.

Future BL4-only data should be added here rather than to the generic editor root.

## Planned data

- Verified BL4 manifest/part database
- Item names and rarity mappings
- Element/stat definitions
- Legal part pools and validation rules
- Weapon, shield, grenade, class mod, enhancement, repkit, and heavy-weapon definitions
